# Connection reliability

The Console adds AI accounts using a provider, one expected email per account, and optional names. Its command receipt is scoped to the signed-in user, tenant, and submitted account details. Reopen the dialog and submit the same details to resume an interrupted request. A sign-in can be retried on its existing account. Cancel the active sign-in before removing a draft account.

Claude, Codex and supported Gemini CLI accounts verify the provider identity in a separate staging home. A mismatch keeps the existing credentials and shows the identity returned by the provider. Copy the original provider link into a private browser window if the browser has another account signed in. API key storage leaves verification pending. Account setup verifies access without sending an inference prompt.

Google moved consumer Free, Pro and Ultra users to Antigravity CLI. Gemini CLI browser enrollment applies to Google accounts that retain Gemini CLI access. An Antigravity personal account uses the native sign-in on its own runner profile. The OS keyring is shared by Antigravity's local clients, so a different home folder on the same Windows user is insufficient to register a second identity safely. Use `agy acp --login` on the intended isolated runner and register that profile. The provider's email remains unverified in Farm unless the integration can independently verify it. See [Google's migration notice](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/) and [Antigravity authentication](https://antigravity.google/docs/install?tab=cli).

`list_ais` reports configured execution limits, job load, and timestamped provider quota observations. `ai_usage_observations` shows reported usage for recent jobs, including the requested and resolved model, effort, and session. Provider quota windows cover the account. Remaining jobs and per-job shares of an account quota window are unknown. Codex can report quota through its app server. Other quota sources remain unknown unless a supported adapter reports them.

`ai_options` shows historical configuration, model listings and access observations. `ai_refresh_models` reads Codex app-server and Gemini CLI catalogs and lists Antigravity models from a configured isolated profile. A catalog entry's access is unknown until a real requested job succeeds. An explicit provider rejection applies to that model and account. After an account change, use `ai_refresh_models(account, retry_model)` to clear the rejection for a future explicit attempt. Plans are never used as evidence of model access.

`list_mcp_connections` lists connection IDs and observed identity fields. Pass `_farm.account` when calling a tool to pin it to the selected identity. An unavailable pinned account returns an error. To make connections interchangeable, set the same nonempty `meta.mcp_pool_group` on every connection in that provider's pool through the registry or an explicit connection update. Reserve this for connections that serve the same workspace and permissions. MCP tests perform a real handshake and list tools on the selected connection. A shared catalog does not establish that every account has access to every listed tool.

MCP transports support configured stdio, Streamable HTTP, and SSE. The OAuth client accepts pre-registered client IDs and secret references, client metadata URLs, and scopes through the provider's MCP registry block. OAuth compatibility depends on server metadata, redirect policy and the supported client flow. Generic MCP does not expose a universal provider identity endpoint.

To enable an automatic dashboard OAuth callback, set `FARM_MCP_OAUTH_CALLBACK_URL` to the public HTTPS URL ending in `/oauth/mcp/callback`, route that path to the same Farm process that started sign-in, and register the exact URL with the provider if required. For servers that accept a loopback redirect, the dashboard can also accept the full redirect URL after authorization. A new token store is activated after the selected connection completes the handshake and lists its tools.

For delegated Claude and Codex jobs, set `FARM_WORKER_MCP_URL` to the Farm's own loopback HTTP MCP endpoint, and set `FARM_WORKER_MCP_TOOLS` to the exact external tool names those workers may call, separated by commas or spaces. Each worker gets a temporary credential scoped to its running job and the initiating user's permissions. The operator can include the selected MCP connection ID in the assignment, and the worker can pass it with `_farm.account`. Gemini CLI on Linux additionally requires `FARM_WORKER_GEMINI_SETTINGS` pointing to root-owned system settings with the same endpoint, the `FARM_WORKER_MCP_TOKEN` environment reference in the Authorization header, and that variable blocked by Gemini's environment redaction. Antigravity does not have automatic worker connection injection.
