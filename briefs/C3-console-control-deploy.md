read that way: **Integrations** (every MCP server / OpenAPI API / AI CLI account the owner connects) and **AI Pools** (accounts, live jobs,
conversations) are the main control surfaces; GTM tools are just some of the integrations. Fixtures must show a general setup too (see below).

`ai_conversations`); keep every read of those tables in ONE module (`console/src/lib/farm/integrations-data.ts`) so the lead can reconcile names at merge.

## Screens
- **Routing:** per capability, the ordered list of pools (drag to reorder with keyboard alternative), enable/disable per pool, default strategy select,
  cache TTL; a live "who would answer now" preview (first eligible account per pool with reason). Saves via `set_route`/`set_strategy` commands.
- **Memory & Evidence:** entity search (company domain / person), entity page with facts table (freshness badge fresh/stale/expired, source account,
  observed date, evidence link), evidence viewer (thumbnail, sha256, captured_at, URL, robots decision; full image when available).
- **Integrations:** catalogue of provider types (API adapter, MCP server, AI CLI, LLM via Bifrost) → "Add" opens an RJSF form (`@rjsf/shadcn`) generated
  from the registry JSON Schema for that provider kind; secrets are never fields — `auth_ref` is an env-var name / token-store id with the exact
  `farm set-secret NAME` / `farm mcp login ID` / `farm ai login ID` command shown after save; "Test connection" enqueues `test_connection` and shows the
  result. Edit/remove existing connections (`update_connection`/`remove_connection` with confirm).
- **Integrations (main screen):** list every connected integration — MCP servers (from OPEN1: transport, namespace, exposure mode direct/discovery,
  accounts, health, last sync, tool count), OpenAPI providers, AI CLI accounts — with search + kind/health filters. Detail page per MCP server: its
  tools (name, description, read-only hint, schema viewer) with per-tool allow/deny toggles, accounts with login state, "Sync tools" and "Test" commands,
  and the exact CLI commands for things only the PC can do (`farm mcp import --from claude-desktop|claude-code|codex`, `farm mcp login <id>`,
  `farm set-secret NAME`). Never a field that accepts a secret value.
- **AI Pools additions (from AIP2):** live jobs table (state, AI, account, elapsed, tokens/cost, cancel), conversations list (AI, account, turns,
  tokens, last activity — metadata only, no transcripts), per-account concurrency (`max_parallel`) control via command.
- **Policies & Budgets:** global + per-provider budgets, hard-stop toggles, alert thresholds, per-caller rules (what Hermes/agents may call), audit log
  table (`audit_events`).
- **Settings:** owner email, timezone, Telegram alert test, data-source indicator, Farm heartbeat/version, links to docs.
